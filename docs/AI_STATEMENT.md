# AI use statement

This statement is based on the entries in [docs/AI_USAGE.md](AI_USAGE.md).

## AI tool and generated work

The usage log names **Copilot** as the AI tool. It records AI-generated work across the project, including the initial scaffold and contract, seeded mission engine and balance simulations, science data and NASA snapshot fetcher, UI components and animated outpost, mission screens, audio and accessibility settings, events, Ghost and rewind behavior, debrief, live Sun banner, achievements, certificate and patch tools, PWA setup, tests, and these submission documents.

## Human work and review status

The repository documents team ownership boundaries and project requirements, but the AI usage log does not identify individual human authors for the generated code or record completed human reviews. Its final column lists work that a human **must** review; it does not establish that the review was completed. In particular, the log does not document completed CAPCOM-copy review, playtests, accessibility review, or verification of the outstanding science citations. The repository contains automated Vitest tests, but the log does not attribute completed test runs to a human.

This statement therefore makes no claim about a human-authored percentage or unrecorded human contributions. Human review and playtest status should be updated here only when the team has evidence of completion.
